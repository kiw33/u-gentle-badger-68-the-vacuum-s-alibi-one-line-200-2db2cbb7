## Entry

`main.py` (Python 3.13, harness program/v1) writes the funniest one-line excuse a robot vacuum can give for missing a spot to `/output/entry.txt`:

> My lidar flagged that corner as a restricted zone. I did not miss the dust — I respected its borders.

(101 characters; gate: 1-200 characters, UTF-8.)

## How it works

No network, no randomness, no input — the program writes a fixed string, so
every run produces byte-identical output. See `BUILD-NOTE.md` for the
verification evidence.
